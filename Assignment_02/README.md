# CampusWheels Vehicle-Rental Desk

## How to Run

Open a terminal in the Assignment_02 folder.
Run:

```bash
py main.py
```

The program demonstrates how vehicles can be rented and returned. It also shows inheritance, polymorphism, and error handling.

## Files

* `rental.py` - Defines the Vehicle, Renter, ElectricCar, and Motorbike classes, including the rental methods.
* `main.py` - Runs examples to test and demonstrate the program.
* `README.md` - Provides information about the project and how to run it.
